# Situation pools H and S (PHASE2.md sections 2-3)

- **H** (`H.json`): the canonical probes of `../C_engine/card_probe.cpp`; every card is run in every H situation.
- **S** (`S_train.json`, `S_test.json`): decisions sampled from 160 real games (`games.txt`), split by game seed (`seed % 10 < 7` -> train).
  Each situation names its game (deck A, deck B, agent A, agent B, game seed) and its decision index, plus the state fingerprint `fp` that `situation_sampler verify` checks after replaying the game.
- Behaviour records per pool: `out/H.json`, `out/S_train.json`, `out/S_test.json`. Per card, they list the distinct behaviours (legality + sparse state delta) and, for each situation (row number in the pool file), the index of its behaviour.
- `out/coverage.json` gives situations per card, pool and kind. `out/ab_effects.json` gives the effect fields seen per pool.
- Raw sampler output is in `raw/` (gitignored). It is rebuilt by `run_sampler.sh` (about 30 s on 12 processes in WSL), then `python build_pools.py`.

Build: `build_sampler.sh` copies the sources into the WSL build copy and builds `card_probe` and `situation_sampler` (`situations.cmake`, EXCLUDE_FROM_ALL).

Kinds in S:
- `play`: an offered play or hide.
- `act`: an offered activation.
- `trigger`: the card's finalized triggered ability is on top of the chain.
  The delta is resolved-with minus resolved-without the item.
- `inplay`: the in-play legality counts.
- `held`: the card is in hand but no play is offered.

`*_sub` marks substitution. Cards not in the two main decks are written over a hand card of the decider: partners, sideboard-only cards, synthetic variants, the Hush stand-in, and Lonely Poro class 777 (the decks resolve to class 359). The host card is chosen from the seeds, and legality is regenerated by a fresh engine.
